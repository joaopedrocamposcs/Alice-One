Perguntas frequentes

O que é o AliceFlow?

O AliceFlow é uma agenda online para organizar tarefas, hábitos, metas e anotações em um só lugar.

Como os dados ficam salvos?

Seus dados ficam no armazenamento local do navegador deste dispositivo; eles não são enviados a um servidor.

Posso usar o AliceFlow no celular?

Sim. A interface se adapta a telas de celular; você pode acessar no navegador do aparelho.

Posso acessar meus dados em outro dispositivo?

Não. Os dados ficam no navegador e no dispositivo em que foram criados, sem sincronização entre aparelhos.

Preciso criar uma conta?

Sim. Cadastre uma conta no AliceFlow para entrar e manter os dados de cada usuário separados no navegador.
